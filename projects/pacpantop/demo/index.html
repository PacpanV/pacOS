pacpantop - lightweight TTY LAN monitor

What it does:
  Scans a local /24 network, reads visible devices from the neighbor table,
  tracks known/unknown devices, and displays status in a terminal interface.

Demo buttons:
  Authorize pending - turns the first pending device into a trusted device.
  Block unknown     - marks the unknown sample device as blocked.
  Reset demo        - restores the fake sample data.
  Man page          - shows or hides this help text.

Real TTY shortcuts:
  a       authorize the first pending/unknown visible device
  b       block the first unknown visible device
  r       reset display state and fetch cache
  m, h, ? open the local pacpantop manual when available
  Ctrl+C  quit pacpantop

Note:
  This browser demo uses fake LAN data. Install pacpantop to monitor a real LAN.

    
Demo mode: this page uses fake LAN data. Browsers cannot run ping, read ip neigh, see MAC addresses, or scan your LAN directly. Install pacpantop to monitor a real local network.
